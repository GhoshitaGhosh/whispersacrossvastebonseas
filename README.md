## 📖 Overview

**W.A.V.E.S.** is an atmospheric survival Real-Time Strategy (RTS) game with a unique horror twist, built entirely in HTML, CSS, and JavaScript using an ASCII aesthetic. You step into the role of a new leader for a coastal settlement on the edge of the world. 

- **By Day (Low Tide):** Command your villagers to gather resources, construct defenses, and prepare for the inevitable.
- **By Night (High Tide):** The ocean surges, and the horrors of the deep emerge from the fog to claim what is theirs.

Guided by the village Elder, you will manage your workforce and fortify your position. But beware—the sea is not your only enemy.

---

## ✨ Key Features

- **Lo-Fi Horror Aesthetic:** Experience a fully animated ASCII world complete with dynamic fog, particle bursts, and screen-shaking impact effects.
- **Strategic Command:** Direct your villagers to gather wood and stone, build protective walls, or man the watchtowers.
- **The Dread System:** Fear is a tangible mechanic. As situations worsen, your screen distorts with hallucinations, and villagers may panic. Keep the Dread low to survive!
- **7 Cycles of Survival:** Defend your Great Hall against escalating waves of enemies, ranging from swarming *Lurkers* to towering *Brutes* and deadly *Extruders*.
- **Narrative Prologue:** Play through "Cycle 0," a narrative-driven beginning that introduces you to the struggle against the void.
- **Single-File Portability:** The entire game runs locally in your browser from a single `index.html` file!

---

## 🎮 How to Play

Playing W.A.V.E.S. is simple—no installation or server required!

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Ensure your browser window is appropriately sized or maximized for the best experience.

### Controls

| Key | Action |
| --- | --- |
| **W, A, S, D** | Move your character |
| **E** | Interact / Reinforce walls (Hold) |
| **F** | Order villagers to follow you |
| **G** | Assign following villagers to a task (Gather / Build / Man Tower) |
| **B** | Open the Build Menu |
| **R** | Rally panicked villagers or un-man a tower |

## 🛠️ Development

This project was refined into a pure, lightweight web-based game. The core logic, rendering engine, UI, and aesthetics are all bundled within `index.html`.

### Customization
To tinker with the game's settings, styling, or logic, open `index.html` in your favorite code editor. You'll find extensive inline documentation, well-organized CSS variables for aesthetics, and modular JavaScript managing the game's state and rendering.
